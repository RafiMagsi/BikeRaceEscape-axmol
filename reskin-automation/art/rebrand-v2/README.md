# Rebrand v2 asset kit

Historical revision. The current runtime and store artwork is documented in
`../rebrand-v3/README.md` and `../../store/rebrand-v3/README.md`.

These are versioned, review-ready assets. The existing production assets are intentionally untouched until the new art is approved.

## Generated assets

- `icon-source-v2.png` — generated app-icon master, kept at the generated 1254px square size.
- `icon-1024.png` — 1024px store icon.
- `key-art-1672x941.png` — generated landscape key art.
- `background-source-2048x768.png` — generated gameplay background source used for atlas crops.
- `layers/layer-0.png` … `layers/layer-8.png` — reviewable scene-layer crops with the original visible alpha preserved.
- `layers/platform-road-bridge.png` — asphalt/concrete slab with the original oblique perspective, pale front face, shaded right face, and original alpha mask.
- `platform-v5/` — generated source, aligned runtime crop, preview, and edit specification.
- `layers/platform-water-bridge.png` — compatibility copy of the current platform asset for existing review links.
- `SCENE_LAYOUT.md` — runtime layer order, z-index relationship, parallax values, and transparency contract.
- `../store/rebrand-v2/header-1920x1080.png` — store header.
- `../store/rebrand-v2/feature-graphic-1024x500.png` — Google Play feature graphic crop.
- `../store/rebrand-v2/search-result-512.png` — search/listing icon.
- `../store/rebrand-v2/app-store-search-result-1024.png` — App Store search-result icon.
- `../store/rebrand-v2/listing/*.png` — five 1920x1080 listing compositions built from real gameplay captures with a consistent cyan/navy frame.

Platform-specific copies are also available at `store/ios/app_store_search_result_1024.png` and
`store/android/app_store_search_result_1024.png`.

The store listing compositions deliberately use actual gameplay captures. They are marketing layouts, not fabricated gameplay renders.
